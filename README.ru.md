# Colab Menu Automation

[English](README.md) | 🌐 **Русский**

Расширение Chrome, которое автоматизирует действия в меню Google Colab: удаление среды, переключение на T4 GPU, открытие блокнотов, выполнение всех ячеек - одним нажатием.

## Установка

1. Откройте `chrome://extensions/`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку `chrome_extenshion_colab_menu_automation`

## Кнопки на панели

После загрузки блокнота Colab расширение добавляет кнопки на верхнюю панель:

| Кнопка | Что делает |
|---|---|
| 🗑 **Откл+удалить** | Среда выполнения → Отключиться и удалить → Да |
| 🟢 **Открыть+** | Файл → Загрузить блокнот → Выбрать файл → **после перезагрузки**: T4 → Выполнить всё |
| 🔄 **T4 GPU** | Среда выполнения → Сменить среду выполнения → T4 GPU → Сохранить |
| 📂 **Открыть** | Файл → Загрузить блокнот → Выбрать файл |
| ▶ **T4 + Вып. всё** | Переключить на T4 → Выполнить все ячейки |
| ⬇ **Скачать .ipynb** | Файл → Скачать → Скачать IPYNB |

Наведите курсор на кнопку - покажется полный путь в меню.

### Автоматизация с перезагрузкой

Кнопка **Открыть+** переживает перезагрузку страницы. После выбора файла в системном диалоге Colab перезагружает страницу с новым блокнотом. Расширение обнаруживает это, переключает среду выполнения на T4 и выполняет все ячейки - полностью автоматически.

## Возможности попапа

Нажмите на иконку расширения на панели инструментов, чтобы открыть попап:

- **Сканировать меню** - рекурсивно сканирует все меню, диалоги и подменю Colab; экспорт в JSON
- **Кнопки** - показать/убрать панель кнопок
- **Закрыть меню** - закрыть открытые меню (Escape)
- **Логи** - скачать, очистить, включить/выключить логирование
- **DOM слепок** - дамп видимых элементов для отладки
- **Тема** - светлая, тёмная или системная

## Как это работает

- **Навигация по меню**: открывает верхнее меню (например, «Файл»), затем использует симуляцию клавиатуры (ArrowDown + Enter) для выбора пункта. Подменю открываются кликом + поиск с polling.
- **Поиск диалогов**: проверяет 18+ CSS-селекторов, включая shadow DOM (`mwc-dialog`, `jp-dialog` и т.д.), с polling до 5 секунд.
- **MWC-радио**: проходит через shadow root, находит нативный `<input type="radio">` и переключает его напрямую.
- **Файловый диалог**: использует только нативный `.click()` - без синтетических событий, что предотвращает повторное открытие диалога.
- **Сохранение состояния**: `chrome.storage.local` хранит флаг ожидающего действия для автоматизации с перезагрузкой. Флаг живёт 60 секунд и удаляется сразу после чтения.
- **Фоновая активность**: отсутствует. Все обсерверы живут максимум 5 секунд и отключаются после использования. Нет `setInterval`, нет фонового polling, нет DOM-наблюдателей вне моментов автоматизации.
